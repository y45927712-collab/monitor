# 🖥️ PC Performance Monitor

A lightweight and responsive web-based application designed to monitor your computer's vital stats in real-time. This tool helps gamers and developers keep track of their hardware performance seamlessly.

## ✨ Features
* **Real-time FPS Tracking:** Monitor your frames per second smoothly.
* **CPU Monitoring:** Keep an eye on processor utilization and load.
* **RAM Tracker:** View active memory consumption to prevent bottlenecks.
* **Lightweight & Fast:** Built using pure frontend technologies with zero performance overhead.

## 🛠️ Built With
* **HTML5** - For structural layout.
* **CSS3** - For modern, responsive, and sleek UI styling.
* **JavaScript (Vanilla)** - For real-time data handling and performance logic.
